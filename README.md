# Sonido Vivo - Tienda de Música Online

**Sonido Vivo** es un proyecto web de e-commerce desarrollado para una tienda de instrumentos y equipos musicales con más de 11 años de trayectoria en Viña del Mar, Región de Valparaíso[cite: 1]. La plataforma ofrece una interfaz moderna, responsiva y fácil de navegar para clientes de todo Chile[cite: 1].

---

## Características Principales

* **Encabezado Personalizado:** Diseño de cabecera tipo e-commerce con isotipo corporativo en cuadrantes, navegación limpia e íconos de acceso directo.
* **Catálogo de Productos:** Exhibición de instrumentos con fichas detalladas y precios.
* **Diseño Responsivo:** Adaptado para una correcta visualización en dispositivos móviles, tablets y computadores.
* **Módulo de Usuarios:** Formularios integrados para inicio de sesión (`login.html`) y registro de nuevos clientes (`registro.html`).

---

## Tecnologías Utilizadas

* **HTML5:** Estructura semántica para las 5 páginas del sitio.
* **CSS3:** Estilos personalizados, Flexbox, CSS Grid y variables de color corporativas (`--primary-color`, `--accent-color`).
* **Font Awesome (v6.4):** Librería de íconos vectoriales para la interfaz de usuario.
